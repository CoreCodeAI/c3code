# Use C3 Code as your default browser

On macOS, you can set the C3 Code desktop app as your default web browser so links from other apps and local HTML files open directly in C3 Code.

## Enable

Choose **C3 Code** in **System Settings → Desktop & Dock → Default web browser** (switch back there anytime).

## How links open

- If the active thread has its browser panel open, the link opens as a new tab there; otherwise C3 Code opens a new no-project thread with the browser panel maximized so you can ask an agent about the page right away.
- Pull request links for connected projects open in the PR view (when **Open pull requests in C3 Code** is enabled).
- [Prompt links](./prompt-links.md) open as a draft, including T3 Code's `app.t3.codes` links.
